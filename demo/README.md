这份 **24 页**的课程实验报告用于展示技能在报告组织、中文排版、图表呈现、代码附录等方面的效果。

## 演示包含什么

- 封面、摘要和独立目录页。
- 研究背景、相关工作、方法、实验设计与结果讨论。
- 数据表、方法示意图、柱状图、混淆矩阵与训练曲线。
- 实验命令、产物索引和参考文献。

## 脱敏范围

姓名、学号、完成日期和原 PDF 作者元数据已移除；部分具体实验数值、参数与结果标注已替换为 `xxx`。原第 10 节及其目录条目已删除，后续页码与目录中的附录页码同步调整。

保留了正文、目录、标题和全部图片的主要内容。图表仍展示坐标、形状和趋势，可估计结果的大致范围，因此这是用于公开展示的轻度脱敏版本，不是对实验信息的完整隐藏。

PDF 由处理后的页面图像重新构建，不带原始文本层、附件、批注、书签或历史修订。截图来自同一份处理后的页面。公开版本不包含原报告的 LaTeX 源文件或实验项目。

## 阅读说明

- `xxx` 是主动替换的演示占位符，不代表实验结果，也不是技能未完成的正文。
- 正文中关于实验产物、命令、图表来源和可复现性的描述属于原报告语境；本仓库不提供这些实验资产。
- 原报告中“图表未手工编辑”等表述描述的是实验报告原稿；公开演示中的部分数字经过隐私处理。
- 图片形状保留不等于结果经过本仓库独立验证。本演示用于观察文档结构和排版。
- PDF 不包含可搜索文字层，阅读时可直接缩放页面；截图提供独立 PNG。
